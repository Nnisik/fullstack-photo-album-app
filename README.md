### Instalation
1. Clone this repo:
   ```bash
     git clone https://github.com/Nnisik/fullstack-photo-album-app
   ```
2. Open project's folder:
   ```bash
     cd fullstack-photo-album-app
   ```
3. Set up backend for work:
   1. Go into backend folder:
      ```bash
        cd backend
      ```
   2. 
4. Set up frontend for work:
   1. Go into frontend folder:
      ```bash
        cd ../front
      ```
   2. Install dependencies:
      ```bash
        npm i
      ```
   3. Run (in developer mode):
      ```bash
        npm run dev
      ```
5. Open in your local browser
